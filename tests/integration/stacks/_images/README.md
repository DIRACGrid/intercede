# Shared stack images

Dockerfiles shared across stacks (`arc/`, `slurm/`, `htcondor-ce/`, …).

Conventions (EL9 base, pinned Renovate-annotated `ARG`s, foreground daemons, ephemeral
credentials, GHCR publishing) are documented in
[docs/dev/reference/integration-images.md](../../../../docs/dev/reference/integration-images.md).
